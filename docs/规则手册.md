## 一、阵营与身份体系

**8 个阵营**：东汉 / 群雄 / 曹魏 / 孙吴 / 蜀汉 / 晋 / 异族 / 神怪。

| 阵营 | 可用身份 |
|---|---|
| 东汉、曹魏、孙吴、蜀汉、晋 | 皇帝、追谥、**君主**、权臣、**客君**、亲族、文臣、武将、女眷、其他 |
| 群雄、异族 | 君主、文臣、武将、**女眷** |
| 神怪 | 仅「其他」，人物卡隐藏身份栏 |

## 二、身份判定优先级（N4 定案 + v1.2）

**皇帝 > 追谥 > 君主 > 权臣 > 客君 > 亲族 > 文臣/武将 > 其他**
女性（异族、神怪除外）不参与竞争，直接归女眷。「君主」与「权臣」互斥：君主是首领，权臣是臣。

## 三、各身份判定细则

**追谥**（魏蜀吴晋专属）：死身后被本阵营皇帝追尊为帝者。看追谥结果不看生前——司马懿在晋归追谥，在曹魏仍权臣。追尊王/侯不算。追谥时间片 = [阵营建立年, 阵营灭亡年]，confidence 1.0。追谥皇后归女眷。特例：孙策（桓王）不入追谥，但作为吴国奠基人归孙吴·亲族 [229, 280]。

**权臣**（N1 方案 A）：满足任一即成立——
- A 组：任丞相／大将军／录尚书事／都督中外诸军事之一 + 实际主持朝政 ≥ 1 年 + 大小国事一决（核实依据：「事无大小皆决于X」「政由葛氏」「专权」「总揽朝政」类表述，原文或史书）
- B 组：公开威胁皇权举动（废立、弑君、逼宫、另立朝廷）。暗地刺杀不算

**亲族**（v1.4 收紧口径）：仅限两类——①**本阵营帝系血亲**（×之子／之弟／之孙／之侄，含追尊）；②**后族**（后妃本人及其父兄，即外戚）。`title` 必须写明系出哪一位君主，仅写封号（如「燕王」「彭城王」）不足以判定。
**不算亲族的三类**：宗室旁支的姻亲（周胤娶孙皎之女，是孙权侄女婿）、功臣之后袭爵（吕霸袭吕蒙孱陵侯、关彝袭关羽汉寿亭侯）、帝系之外的同姓（司马炎之于曹氏）。这三类归文臣／武将。
群雄/异族不设——曹仁曹洪在群雄时期归武将，称帝后归亲族。校验见 `audit_persons.py` 的「亲族无血亲线索」「亲族帝系不明」。

**客君**（v1.4 新增）：非本朝帝系、而以「前朝／他国君主」之身受本朝封爵者，即本朝的「宾」。与亲族的区别是无血缘；与其他的区别是仍有明确的前朝君主身份。时间片 = [受封年, 卒年]。

| 人物 | 前朝身份 | 受封 |
|---|---|---|
| 刘协 | 汉献帝 | 220–234 曹魏·客君（山阳公） |
| 刘禅 | 蜀汉后主 | 263–266 曹魏·客君（安乐公）→ 266–271 晋·客君 |
| 曹奂 | 魏元帝 | 265–302 晋·客君（陈留王） |

**文臣 / 武将**：文臣以谋略内政为主，武将以战斗指挥为主。职责不明按最高官职判断；无官职名者不归文臣、默认归武将。

**女眷**：所有非异族、非神怪的女性（太后、皇后、公主、妃嫔、宗室女、重臣妻女）。异族女性按职责归武将等（祝融夫人→武将）。

## 四、神怪入营标准（N3 定案）

**有超自然能力表现，且不属于任何政治军事集团** → 神怪。
入营：南华老仙、于吉、左慈、紫虚上人、普净。
不入营：张角（→群雄·君主）、华佗（→东汉·其他）、管辂（→曹魏·其他）；关羽死后显圣只作时间线节点不改身份。

## 五、无政治归属者（N5 定案）

统一归东汉，身份按职业：华佗/司马徽/十常侍/祢衡→其他；貂蝉→女眷。220 年后出现者按活动地域归所在政权，无法判定标 disputed。

## 六、收录与链接口径

- 收录：有名有姓出场者；有名无姓者；**有姓氏或固定称谓的女性**；完全无名但承担不可替代情节功能者（标 `is_nameless`，预计 ≤ 30 人）。仅提及未出场不收录。
- 链接：全称 + 单称 + 别称都弹卡；`is_weak_link = true` 的锚点只给提示、不弹卡。
  > **口径更正（2026-10-27）**：此处原写「官职代称悬浮提示不弹卡（`is_weak_link`）」，把「设计意图」当成了「现状」。
  > 实测 74 条弱链接**全部**是 `source = anaphora` 的单字回指（嵩/进/让/信/表/良/汜/融/攸），官职代称通道尚未产出任何锚点。
  > 因此 `is_weak_link` 当前的实际含义是「**证据不足的回指推定**」，判定标准见第 240 行回指消歧一节。
- 生卒年：约 / 不详 / 存疑 三档 + 依据说明；不确定输出 null，**禁止推测年份**。


## 七、事件与战役（N7 定案 + P1-D 执行细则）

事件是「统摄一段历史的容器」，战役是其中「有战线可画」的子类型。P1-D（第 2–10 回，11 组事件 / 9 场战役）在此基础上定下四条执行细则：

1. **「军事行动」类轻量父事件**允许统摄多场战役，也允许一场战役都不挂（如十常侍之乱是「宫廷政变」，挂的是「北邙山之变」这类非典型战役——有人员、有地点、有先后，就可画战线）。
2. **事件卡必须带原文链接**。passage_ids 由 `scripts/gen_events_p1d.py` 以「(回数, 原文关键词)」在构建产物中解析生成并断言存在，**禁止手填段落 id**——段落重排会让手填 id 全部变成死链，且不报错。
3. **人物引用必须建档**。participants / commanders 只允许引用 `persons_*.json` 中存在的 id，脚本断言；未建档者在 P1-F 补卡后恢复，此前降级为详情文字。
4. **时间线允许一段区间**。事件的 start_year/end_year 是「影响所及的区间」（如李傕郭汜之乱 192–196），timeline 各节点 year 落在区间内即可；不必与战役的 year 严格重合。

## 八、阵营与时间片（2026-10-27 P0 修订）

**核心原则：人物的历史身份由「势力」决定，不由「国号」决定。**

| 概念 | 字段 | 含义 |
|---|---|---|
| 国号年 | `faction.start_year` | 史实建号年（曹魏 220、孙吴 229、蜀汉 221） |
| 势力形成年 | `faction.de_facto_start` | 该势力实际形成之年，**时间片校验下限用它**：魏 196 迎帝都许、吴 195 孙策渡江、蜀 208 取荆南四郡 |
| 所事之主 | `tenure.lord_id` | 群雄阵营人物必填；UI 按 lord 归入其政权视图 |

- 群雄是**类别**不是政权，存续 184–229（至孙权称帝、鼎立完成）
- 例：关羽 200–208 记「群雄·武将 + lord_id=刘备」，数据层为群雄，界面归蜀汉；208 起记「蜀汉·武将」
- 例：刘备 184–221 记「群雄·君主」，221 起记「蜀汉·皇帝」
- 时间片相邻允许 1 年误差（整数年边界）；死亡到追尊/追谥之间的空档豁免（孙策：卒 200，孙吴·亲族片自 229 起）
- 校验器 `scripts/validate_cards.py` 已按本节实现，共 11 类规则

## 八之二、演义与史实冲突（P1-1 定案 · v1.3）

**方案 A**：正文一律从演义，史实差异只在卡片上作注。**触发条件为硬冲突**，**史异写独立字段**，不进 `bio` / `summary` / `date_note`。

### 8.2.1 什么算史异（2026-10-28 定案：A1 阈值 = 硬冲突四类 + 重大叙事）

判据两句话：① **硬冲突**——演义与史书对「同一事实」给出互相排斥的结论，且需要一句「史为…」才能说清；② **重大叙事**——演义整体虚构但深刻参与人物形象塑造的著名桥段（史书无此事），也须标注，防读者把虚构叙事当史实。按五类归档，填 `history_conflict_type`：

| 类型 | 判据 | 例子 |
|---|---|---|
| 功劳归属 | 同一件事的承担者被换成另一人 | 关羽斩华雄 ↔ 孙坚破董卓军所斩；草船借箭 ↔ 孙权 |
| 事件有无 | 演义详述而史书无载，或事件性质被改写 | 空城计、连环计 |
| 职官归属 | 官衔 / 隶属与史书矛盾 | 丁原「荆州刺史」↔「并州刺史」 |
| 生死结局 | 死亡时间、原因或生死状态与史书矛盾 | 华佗、于吉（见 8.2.4） |
| 重大叙事 | 整体虚构、史书无此事、但已成为人物形象不可分割的著名桥段 | 过五关斩六将、三英战吕布（v1.3 原归「事件有无」，A1 拆出单列） |

**不算硬冲突（只进 `date_note`，不填 `history_conflict_*`）**：

- 单纯年份差（某人史载卒年与演义情节年差几年，但情节与结局不矛盾）；
- 岁数、行程快慢、兵力与粮草数字；
- 演义详于史书而史书只是「失载」（史书没说过相反的话，就不是冲突，是缺环）。

### 8.2.2 字段与填写规则

| 字段 | 类型 | 规则 |
|---|---|---|
| `history_conflict_type` | enum | `功劳归属`／`事件有无`／`职官归属`／`生死结局`；无硬冲突填 `null` |
| `history_conflict_note` | text | 一两句，固定句式「演义…；史实…」。只陈述差异，不做评价、不引未经核对的细节 |

- 两者**必须同时有值或同时为空**，校验器 `validate_cards.py` 报 `CONFLICT` 错；
- 同一差异**不得在 `bio` / `summary` / `date_note` 里再说一遍**，防两处表述走样；
- 一张卡有多处硬冲突时，`history_conflict_type` 取**主项**（影响最大的一处），其余差异用分号串在同一个 note 里，不新建字段。

### 8.2.3 呈现位置（2026-10-28 修订）

人物卡「史异注」栏（原「史实注」，随定案更名）**不折叠**，固定渲染在**卡片最底部**（「生平详述」之后、「出现位置」之前），浅色底、字号小一号；无冲突者整块不渲染，不留空标题。

### 8.2.4 生卒年双标（2026-10-28 新增）

演义与史书对**生卒年**记载不同时，不走 `history_conflict_note`（那是事件级冲突），改用独立字段 `history_life_dates`（字符串）：卡片头部演义生卒年下方以小字标出「史书生卒：…」，一句说清史书口径。适用案例：吉平（演义 200 / 史书原型吉本 218）、于吉（演义 199 / 史书卒年不详）。`date_note` 仍只写演义口径的年份与缺端说明。

### 8.2.4 两个已入档案例

| 人物 | history_conflict_type | history_conflict_note | date_note（只写年份口径） |
|---|---|---|---|
| 于吉 | 生死结局 | 演义作孙策于建安四年（199）斩于市；史传为汉顺帝时（125–144）已在琅琊宫学道之方士，卒年不详 | 卒年 199 取演义情节年；史载活动于顺帝朝 |
| 吉平 | 事件有无 | 演义作建安五年（200）衣带诏事泄被拷死；史实原型为太医令吉本，反曹在建安二十三年（218） | 卒年 200 取演义情节年；史实原型 218 年被杀 |
| 华佗 | 生死结局 | 演义作曹操头风、欲开颅被杀；史书为曹操屡召不至、下狱拷死，时在建安十三年（208）前后 | 演义与史书卒年相差十余年，两端均不精确 |

> **于吉与吉平是两个人**（`yu_ji` 神怪·琅琊道士 / `ji_ping` 东汉·太医令），不合并。两者同属「卒年取演义情节年」这一类处理，不构成合并理由。

### 8.2.5 对已入库卡片的处置

P1 已批产的 240 张卡是**把史异写在 `date_note` / `bio` 里**的，与新口径的差别是「位置」而非「内容」。处置：

1. `date_note` 中形如「演义…史实/史载…」的句子，迁入 `history_conflict_note` 并补 `history_conflict_type`；
2. `date_note` 只保留年份精度与缺端说明（生年不详等）；
3. 迁移脚本 `scripts/migrate_conflicts.py` 只做**候选提取**（按「演义」「史实」「史载」「当从」等词），迁移结果标 `review_status=auto_generated`，**须人工确认类型后再转 reviewed**——机器判类型会错；
4. 迁移前后 `verify.py` 必须保持 61 项全绿，且不得新增 `CONFLICT` 错。

## 九、地图坐标（P0 验证结论）

- 使用**图像坐标系**（像素），不用经纬度；每地名自带预设锁定比例，`minZoom = maxZoom`
- 战线动画的相机由**脚本**控制（全程视角 → 逐节点推镜 7×），用户侧始终禁止缩放
- 换谭图时只替换 `CANVAS` 与底图图层，投影与业务代码不变

## 十、生卒年精度（P1-B 补丁 D）

`date_precision` 描述的是**已填年份**的精度档，不是整张卡的完整度。

- 生年不详而卒年确切是常态（《三国志》多不载生年），此时标 `exact` 合法
- 但 `date_note` 必须注明哪一端缺失（含「生年不详」「卒年不详」或「生卒年皆不详」字样）
- 若按「最短板」解释，几乎所有人物都要降为 `approx`，反而丢掉「卒年确切」这个有用信息

| 档位 | 含义 | 约束 |
|---|---|---|
| exact | 已填年份确切 | 至少一端有年份 |
| approx | 约（推算或史料互异） | — |
| unknown | 不详 | birth / death 必须为 null |
| disputed | 存疑（史料冲突） | 须在 date_note 说明冲突来源 |

**硬规则**：年份不确定时输出 `null`，禁止推测。校验器另有寿命合理性检查（10–105 岁），用于抓「把两个人的年份拼到一张卡」这类硬错。

## 十一、单字单称链接（P1-B 新增，全书级）

演义对白大量用单字单称（「坚曰」「操曰」「允曰」）。第 1–10 回实测：「X曰」共 222 处，其中 **183 处（82%）的 X 唯一对应已建档人物，且只涉及 30 个单字**。不做单字链接，读者点正文里紧挨全称的「坚」「操」毫无反应——这是用户最先感知到的缺陷。

**启用条件（必须同时满足，缺一不可）**：

1. 前一字是**标点、空白**，或位于段首，**或为言语动词**（问/谓/告/召/请/命/令/见/与/从/随）
2. 后接词落在允许集内（曰/怒/喜/惊/叹/叱/喝/笑/谏/奏/大/亦/乃/又/便/自/即/谓/呼 等）

两个条件写成 AND 而非 OR，是这套机制能成立的关键。只写 OR 会把「坚守」「操练」「允许」「公乃」全部放进来。

第三类前置条件（v1.2 新增）：第 9 回「卓**问**肃曰」的「肃」前一字是「问」，不在标点白名单里，于是漏链。放宽前置为「标点 ∪ 言语动词」，但**后置条件不变**——仍必须命中言语动词。两条并存，缺一不可。

## 十二、同段回指消歧（P1-C 新增，全书级）

单字通道只放行「末字全局唯一」的字。剩下两类被挡在门外：

1. **末字撞车**：良（颜良/蒯良）、嵩（皇甫嵩/曹嵩）、瑁（乔瑁/蔡瑁）、攸（荀攸/许攸）
2. **末字是高频动词/名词**：表（上表）、信（书信）、禁（禁止）

第 6–8 回「表曰」出现 5 次，全是刘表；第 7 回「良曰」出现 2 次，全是蒯良。同类问题在 120 回里会线性放大。

**判据不是字面，而是上下文**。三条同时成立才链接：

1. 前一字是标点/闭合引号，或为言语动词
2. 后接言语动词
3. **同一段落内**，该字之前出现过「以此字结尾的全称」，且最近的一个唯一

```
第6回 …相逼邻郡？"表曰："汝匿传国玺…     ← 前文有「刘表」  → 刘表
第7回 问刘表借粮二十万，表亦不与。          ← 紧邻「刘表」    → 刘表
第7回 表慌请蒯良商议。良曰："目今新败…      ← 紧邻「蒯良」    → 蒯良
第10回 往琅琊郡取父曹嵩。嵩自陈留避难…      ← 紧邻「曹嵩」    → 曹嵩
```

**关键案例**：第 1 回有两处「嵩曰」——

- 「惊告嵩，嵩急视之。操故无恙。嵩曰」 → 最近全称是「曹嵩」→ 曹嵩
- 「皇甫嵩、朱儁，具道卢植之意。嵩曰」 → 最近全称是「皇甫嵩」→ 皇甫嵩

同一字面指向两人，靠最近全称各归其主。纯字符规则在这里必错其一。

**为什么只在本段内回指**：跨段回指需要篇章级共指（谁是当前话题、有无插叙），误配代价远高于漏链。宁可漏，不可错。

**标注方式**：这类锚点带 `source: "anaphora"` 与 `anaphora_basis`（依据的全称）。阅读器把它画成**虚线 + 略淡**，悬浮提示写「按同段前文『曹嵩』推定」——让读者知道这处是推定，不是硬事实。

**质检结果**：25 处逐条过目，25/25 正确。与词典锚点零重叠、零切片错位。

**配置位置**：`data/lexicon-rules.json` → `anaphora` 块。`chars` 列出允许回指的字，`exclude` 列出永不参与的字（公/帝/后/遂）。

**已知缺口**：仅同段。跨段落的人物单称（换段后仍用单称）仍需篇章级共指，留到 P2。

## 十三、家族语境与异族关键词（v1.5 新增，全书级）

### 13.1 规则

`infer_from_note()` 的异族分支关键词（羌 / 蛮 / 胡 / 匈奴 / 乌桓 / 鲜卑 / 番 等）**只在本人的直述语境里生效**。注记中出现的是「其妻 / 其母 / 其媳 / 杂处 / 联姻 / 娶 X 女」等**亲属关系语境**的族群词时，不得作为本人阵营依据：

| 案例 | 注记 | 误判 | 正判 |
|---|---|---|---|
| 马肃 | 「失官流落陇西，与羌人杂处，遂娶羌女生腾」 | 异族 | **东汉 · 武将**（天水兰干县尉，桓帝朝 147–167） |
| 马腾 | 同上语境（本人应募从军讨羌） | — | 群雄 · 君主（西凉起兵自成一系，非族群领袖） |

判定要领：族群词描述的是**谁的血统 / 谁的居地 / 谁的婚姻**。描述亲属或居地 → 不判异族；描述本人是族群首领 / 部帅 / 单于 / 洞主 → 才判异族。

### 13.2 防回归

- `verify.py`「简介职任段阵营与本片归属一致」交叉校验（简介写「东汉县尉」而片归异族 → FAIL）；
- 已知误伤案例（左丰、吕岱、马肃等 18+ 条）全部改判入档，改判依据写在 `tenure.basis`，不再靠关键词表打补丁。

### 13.3 全书铺量口径（v1.5 定版）

- 1,171 张卡 = 人工考据卡（reviewed/verified）+ 自动铺量卡（`expand_persons.py`，`auto`/`auto_mined`）+ 正史补录卡（`is_novel_absent`，演义未载、无正文锚点、不参与共现统计）；
